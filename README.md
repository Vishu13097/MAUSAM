# 🌦️ MAUSAM

### Personalized Weather Experience

MAUSAM is a personalized weather web application designed to present weather information based on the user's preferences, interests, and lifestyle.

Instead of showing the same weather information to everyone, WE are focusing on making weather information more relevant and useful for different types of users.

---

## 🚀 Features(upcoming)

- 🌤️ Personalized weather experience
- 👤 User persona selection
- 📍 Location-based weather information
- 🌡️ Weather information presented through simple visual cards
- 🔔 Personalized weather alerts
- 📱 Responsive and user-friendly interface
- 🔥 Firebase integration for backend services
